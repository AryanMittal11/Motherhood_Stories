# Motherhood Stories

Motherhood Stories is a heartfelt blog platform dedicated to celebrating the strength, wisdom, and love of mothers. It features inspiring stories, practical advice, and insights on motherhood, health, and family traditions. The platform is designed with a modern, responsive UI and offers a seamless reading experience.

---

## 🚀 Project Features

- **Hero Carousel**: Highlights featured articles with smooth transitions.
- **Category Explorer**: Browse articles by categories like *Stories*, *Health*, and *Inspiration*.
- **Article Detail Pages**: Rich content view with author bios and related articles.
- **Search Functionality**: Easily search for stories and topics of interest.
- **Responsive Design**: Optimized for both desktop and mobile experiences.
- **Dark Mode**: Toggle between light and dark themes.
